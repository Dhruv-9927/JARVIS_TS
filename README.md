# JARVIS TS - Advanced Voice Neural Network

JARVIS TS is a cutting-edge web application that provides a sophisticated voice and text interface, powered by the incredible Gemini API. It's built with modern web technologies to create a seamless, interactive, and visually stunning AI assistant experience.

## Features

- 🎙️ **Real-time Voice Interaction**: Uses the Gemini Live API for low-latency, natural voice conversations.
- ⌨️ **Text Mode**: Switch seamlessly between voice and text inputs depending on your preference.
- 🌐 **Bilingual Support**: Fluent in both English and Hindi.
- 🎨 **Sleek UI**: A visually striking interface featuring an interactive Arc Reactor visualization, system statistics, and holographic components.
- 🌓 **Light/Dark Modes**: A dynamic theme system that adapts to your environment.
- ⚡ **Built with Modern Tech**: Powered by React 19, TypeScript, Vite, and Tailwind CSS.

## Getting Started

### Prerequisites

You will need a Gemini API Key to run this application. You can get one from [Google AI Studio](https://aistudio.google.com/).

### Installation

1. Clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Create a `.env` file in the root directory and add your Gemini API Key:
   ```env
   VITE_GEMINI_API_KEY=your_api_key_here
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
